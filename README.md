# grok-pstack

Grok Build port of [pstack](https://github.com/cursor/plugins/tree/main/pstack) (`0.15.29`) by [Lauren Tan (poteto)](https://x.com/poteto), bundling `deslop`, `control-cli`, and `control-ui` from [cursor-team-kit](https://github.com/cursor/plugins/tree/main/cursor-team-kit) (`1.2.0`) by Eric Zakariasson.

See the [upstream pstack README](https://github.com/cursor/plugins/blob/main/pstack/README.md), [upstream cursor-team-kit README](https://github.com/cursor/plugins/blob/main/cursor-team-kit/README.md), and the [guide](./docs/guide/README.md) for usage and documentation.

## Install

Install the plugin with the Grok Build CLI:

```bash
grok plugin install https://github.com/pstack-ports/grok-pstack --trust
```

Verify the installation:

```bash
grok plugin list
```
